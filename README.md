# Telco Churn Analysis and Modeling

## About the Project
Telco Churn Analysis and Modeling is a machine learning project that analyzes customer churn patterns in the telecommunications industry. It identifies factors associated with customer attrition and develops predictive models to support customer retention strategies.

## Objectives
- Analyze customer data and identify churn patterns.
- Perform exploratory data analysis (EDA) and data visualization.
- Clean data and perform feature engineering.
- Build and evaluate machine learning classification models.
- Generate insights to support customer retention.

## Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, XGBoost, LightGBM
- **Environment:** Jupyter Notebook

## Topics Covered
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering and Selection
- Customer Churn Analysis
- Decision Tree Classifier
- Random Forest Classifier
- XGBoost Classifier
- LightGBM Classifier
- Stacking Classifier
- Model Training and Evaluation
- Churn Prediction

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebooks in the `notebooks/` directory to explore the data analysis, feature engineering, and machine learning models.
